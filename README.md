# Carbeat Kz

Портфолио-сайт студии AI видео-клипов. Композиция и анимации вдохновлены futuredeluxe.com.

## Структура

```
index.html          — разметка страницы
css/style.css       — стили
js/main.js          — анимации (hero-canvas, reveal текста, часы, cookie bar)
assets/hero/        — сюда положить showreel.mp4 (hero-видео)
assets/clips/       — сюда положить 3 видео-клипа
assets/posters/     — сюда положить 5 постеров
```

## Как заменить заглушки

**Hero:** в `index.html` замените `<canvas id="heroCanvas">` на закомментированный рядом тег `<video>`, положив файл в `assets/hero/showreel.mp4`.

**Карточки:** внутри `.card-media` замените заглушку на
`<video src="assets/clips/clip-001.mp4" autoplay muted loop playsinline></video>`
или `<img src="assets/posters/poster-001.jpg" alt="">` — стили подхватятся автоматически (добавьте `width:100%; height:100%; object-fit:cover`, класс можно взять `.hero-media`).

## Подключение формы заказа (Google Таблица + Telegram)

Заявки с формы «Заказать клип» уходят в Google Apps Script, который пишет их в Таблицу и шлёт сообщение в Telegram. Настройка занимает ~10 минут:

**1. Google Таблица + скрипт**
1. Создайте новую Google Таблицу (например, «Carbeat — Заявки»).
2. Меню: Расширения → Apps Script. Удалите заготовку и вставьте код из `google-apps-script/Code.gs`.
3. Слева: Настройки проекта (шестерёнка) → Свойства скрипта → добавьте два свойства:
   - `TG_TOKEN` — токен бота (шаг 2)
   - `TG_CHAT_ID` — ваш chat id (шаг 2)
4. Справа вверху: Развернуть → Новое развертывание → тип «Веб-приложение»:
   - Запуск от имени: **меня**
   - Доступ: **все**
5. Скопируйте URL веб-приложения (`https://script.google.com/macros/s/…/exec`).

**2. Telegram-бот**
1. В Telegram напишите @BotFather → `/newbot` → получите **токен**.
2. Напишите своему новому боту любое сообщение (иначе он не сможет писать вам).
3. Узнайте свой **chat id**: напишите @userinfobot — он ответит числом.
4. Впишите токен и chat id в свойства скрипта (шаг 1.3).

**3. Сайт**
- В `js/main.js` замените `PASTE_YOUR_APPS_SCRIPT_URL_HERE` на URL из шага 1.5.

**Проверка:** в Apps Script запустите функцию `testSubmit` — в таблице появится тестовая строка, в Telegram придёт сообщение.

**Приоритизация:** скрипт сам считает приоритет по бюджету, срочности и готовности трека и пишет его в таблицу и в сообщение: 🔥 Горячий / ⚡ Средний / ❄️ Холодный.

## Запуск локально

Просто откройте `index.html` в браузере, либо:

```
python3 -m http.server 8000
```
